# 풀 근거 검증 결과 (2026-11-25)

[00_TechPool.md](00_TechPool.md)의 후보 중 근거 약함 표시 34개와 씨앗에 쓰인 82개(겹침 11개, 합 105개)의 "뿌리"를 독립 에이전트 셋(작성자와 다른 컨텍스트)이 웹 자료로 대조했다. 항목의 "비틀어 쓰기"는 게임 설계라 대조 대상이 아니다. **풀 문서는 아직 고치지 않았다.** 사용자가 이 결과를 본 뒤에 고친다.

판정 기준: 확인 = 출처 실재 + 개념 일치 / 부분 = 출처는 있으나 항목이 더 나아감 / 못 찾음 = 출처나 용어를 찾지 못함 / 틀림 = 귀속 오류.

검증 한계: 에이전트가 쓴 검색 요약 도구가 작은 모델이라 일부 근거(OA 일부, Atomic Rockets의 일부 절, Culture 쪽)는 요약문 기준이다. 각 행의 근거 칸에 그렇게 표시했다. 항목당 검색 3회 제한을 넘긴 것이 몇 개 있다. 검색 결과 한 건에 AI에게 지시하는 문구가 섞여 있었으나 무시했고 판정에 영향이 없다.
