# 퀘스트 씨앗 모음

작성 시작 2026-11-24. 스페이스 오페라, 하드 SF, 우주론, 신앙과 사이오닉을 다루는 작품과 자료에서 "이 게임에서 일어날 법한 일"을 모은 창고다. 완성된 퀘스트가 아니라 씨앗이다. 마음에 드는 것을 골라 [QuestSystemDesign.md](../QuestSystemDesign.md)의 사건 형식으로 옮긴다.

전제는 [GameConcept.md](../GameConcept.md)를 따른다. 혼자, 배 한 척, 동면을 되풀이하며 우주의 끝까지 간다. 사건은 선택지 창이 아니라 배 어딘가의 변화로 나타난다. 육체적 전투는 거의 없다.

## 모으는 기준

- 핍진성이 있으면 모은다. 실제 과학, 잘 짜인 설정, 오래 살아남은 이야기 틀이 근거다.
- "창이 깨진다" 같은 흔한 고장은 모으지 않는다. 그 시대에만, 그 상황에서만 일어나는 일을 모은다.
- 남의 작품에서는 **틀과 원리만** 가져온다. 고유 이름, 인물, 세력, 문장은 가져오지 않는다. 씨앗 안에서는 우리 말로 새 이름을 붙인다. 어디서 왔는지는 "뿌리" 칸에 작품 이름으로만 적는다.
- 혼자 있는 사람과 배 한 척에게 일어날 수 있는 모양으로 바꿔 적는다.

## 씨앗 한 개의 모양

```
### 제목
시기: ... · 노리는 곳: 배 / 나 / 일손 / 앎 · 결: 과학 / 신앙 / 사이오닉 / 초월 / 만남 / 유물

한 줄: 무슨 일인지 한 문장.

- 징후: 배 어디에서 무엇이 보이거나 들리나.
- 가지: 할 수 있는 일 3~5개. "→" 뒤에 결과. 가진 테크나 물건에 따라 열리는 가지를 하나 이상 넣는다.
- 방치: 두고 자면 어떻게 되나. (나빠짐 / 잦아듦 / 좋아짐 / 섞임)
- 물체: 이 일에 필요한 물건, 또는 끝나고 남는 물건.
- 엮임: 다른 어떤 일과 이어질 수 있나.
- 뿌리: 어떤 과학이나 작품의 어떤 틀에서 왔나.
```

## 물체 한 개의 모양

각 파일 끝에 "물체" 장을 둔다.

```
| 이름 | 무엇인가 | 배에 두면 | 위험 | 뿌리 |
```

## 이어서 할 일

수집은 "그만"이라고 할 때까지 계속한다. 다른 컴퓨터나 새 세션에서 이어 갈 때 이 장을 본다.

1. **1차 묶음 다시 모으기.** 위 표에서 "없음"인 일곱 묶음을 모은다. 04는 물체 표와 규칙 장만 채운다. 묶음마다 주제에 맞는 자료를 웹에서 찾고, 씨앗 모양을 지켰는지와 남의 작품의 고유 이름이 본문에 섞이지 않았는지 확인한다.

   묶음별로 찾아볼 것:

   | 묶음 | 찾아볼 것 |
   |---|---|
   | 01 | 먼 미래 연표, 우주의 다섯 시대, 축퇴 시대와 양성자 붕괴, 블랙홀 증발, 열죽음과 빅 립과 가짜 진공 붕괴, 볼츠만 두뇌, 다이슨의 영원한 지성, 은하들이 지평선 밖으로 사라지는 일 |
   | 02 | Orion's Arm 백과의 지성 단계와 단계 넘기, 초지성이 돌보는 영역, 옛 인류 보호 구역, 이해 못 할 유물, 생각의 감염, 폭주하는 지성, 웜홀 망. Culture, Diaspora, Accelerando, A Fire Upon the Deep |
   | 03 | Warhammer 40,000의 기술 사제와 기계의 영, 성물이 된 설계도, 순례 함대, 잠든 기계 문명. A Canticle for Leibowitz, Dune, Hyperion, Anathem, 세대 우주선의 종교, 화물 숭배. 수억 년을 건너온 내가 신화가 되는 일 |
   | 05 | 다이슨 구, 링월드, 별 엔진 같은 거대 구조물. 말 없는 방문체, 탐사선, 씨앗선. Roadside Picnic식 원리 모를 유물, 변칙 물체. 스트레인지 물질, 우주 끈, 떠돌이 행성. 책, 악기, 사진 같은 작은 물건 |

3. **통합.** 묶음이 쌓이면 물체만 모은 통합 목록과, 시기별로 다시 묶은 찾아보기를 만든다.
4. **고르기.** 마음에 드는 씨앗에 표시하면 [QuestSystemDesign.md](../QuestSystemDesign.md)의 사건 형식으로 옮겨 지도에 올린다.

조사를 맡길 때 지킬 것은 위 "모으는 기준"과 같다. 한 묶음은 씨앗 35개 이상과 물체 20개 이상을 목표로 한다.
