# 퀘스트라인 001~025: 별과 천체, 시간과 동면

형식과 읽는 법은 [README.md](README.md)에 있다.

## 별과 천체

### 001. 부정맥
조건: 무작위 · 시기: 출발 무렵 · 노리는 곳: 배

1. 태양풍 세기가 불규칙하게 뛴다. 부정맥이 있는 심장 박동 같다. → 차폐 상태를 점검한다.
2. 플레어가 길어져 선체를 쓸고 지나간다. 볕 쪽 외피가 달아오른다. → 방열 대책을 세우거나 배를 돌려 세운다.
3. 박동 간격이 점점 벌어진다. 별이 부풀고 있다. → 채취를 접고 떠날 준비를 한다.
4. 박동이 멈춘다. 몇 시간 뒤 별이 무너진다. → 준비가 덜 됐어도 좌표를 찍고 잔다.

### 002. 느린 빛
조건: 무작위 · 시기: 성간 시대 · 노리는 곳: 앎

1. 스캐너가 말하는 소행성 위치와 창으로 보이는 위치가 다르다. → 어느 쪽을 믿을지 정한다.
2. 드론이 "없는" 돌에 부딪혀 부서진다. → 드론 경로를 손으로 잡아 준다.
3. 이 영역에서는 빛이 몇 시간 늦게 온다는 것을 알아낸다. 보이는 것은 전부 과거다. → 분석해서 항법을 보정한다.
4. 영역이 넓어진다. → 떠나거나, 늦게 오는 빛을 이용해 이미 사라진 것을 관측한다.

### 003. 조용한 구역
조건: 무작위 · 시기: 성간 시대 · 노리는 곳: 일손, 나

1. 통신기에 잡음조차 없다. 고장인 줄 안다. → 통신기를 점검한다. 이상이 없다.
2. 드론과의 연결이 끊긴다. → 직접 불러들이거나 포기한다.
3. 배 안의 소리도 작아진다. 내 발소리가 안 들린다. 무드가 빠르게 깎인다. → 버티거나 원인을 찾는다.
4. 구역 한가운데에 소리를 먹는 물체가 있다. → 가져가서 유물로 삼거나 두고 떠난다.

### 004. 쌍둥이 행성
조건: 무작위 · 시기: 성간 시대 · 노리는 곳: 앎

1. 스캐너에 같은 행성이 둘 잡힌다. 중복 오류처럼 보인다. → 스캐너를 재보정한다. 여전히 둘이다.
2. 한쪽에서 캔 자리와 똑같은 구멍이 다른 쪽에도 나 있다. → 채취를 계속할지 정한다.
3. 한쪽에 내려보낸 드론이 다른 쪽에서도 올라온다. 드론이 한 대 늘었다. → 늘어난 드론을 받을지 정한다.
4. 맞은편 궤도에 내 배와 똑같은 배가 떠 있다. → 신호를 보내거나 조용히 떠난다.

### 005. 얼음 밑의 불빛
조건: 무작위 · 시기: 전 시기 · 노리는 곳: 배

1. 별 없이 떠도는 행성의 얼음 밑에서 규칙적인 불빛이 보인다. → 드론을 내려보낼지 정한다.
2. 드론이 얼음을 뚫자 불빛이 드론을 따라 움직인다. → 채취를 계속하거나 물러난다.
3. 불빛이 궤도의 배를 향해 올라온다. 얼음이 갈라진다. → 고도를 올리거나 맞이한다.
4. 올라온 것이 선체에 붙어 온기를 빨아들인다. → 떼어 내거나, 온기를 나눠 주고 무엇을 주는지 본다.

### 006. 꼬리 속의 씨앗
조건: 무작위 · 시기: 전 시기 · 노리는 곳: 배

1. 혜성 꼬리를 지난 뒤 외피에 고운 가루가 붙어 있다. → 닦아 내거나 표본을 뜬다.
2. 자고 일어나니 가루가 실처럼 자라 이음매를 따라 뻗어 있다. → 긁어내거나 분석한다.
3. 실이 공허부식이 난 자리를 메우고 있다. 그 자리는 부식이 멈췄다. → 기를지 없앨지 정한다.
4. 실이 창을 덮기 시작한다. 안으로도 들어온다. → 가두어 기르는 법을 찾거나 전부 태운다.

### 007. 중력의 파도
조건: 무작위 · 시기: 거대 공학 시대 · 노리는 곳: 배, 나

1. 일정한 간격으로 배가 미세하게 늘어났다 줄어든다. 컵의 물이 흔들린다. → 원인을 찾는다.
2. 간격이 짧아진다. 이음 고리가 삐걱대고 멀미가 난다. → 약한 이음매를 보강한다.
3. 가까이에서 블랙홀 둘이 서로를 돌며 다가가고 있다. → 합쳐지는 순간을 계산한다.
4. 합쳐지기 직전이다. → 떠나거나, 남아서 관측하고 큰 깨달음을 노린다. 남으면 선체가 크게 상한다.

### 008. 식은 별의 주민
조건: 시간 · 시기: 끝 무렵 · 노리는 곳: 앎

1. 다 식은 별의 표면에 반듯한 선이 보인다. → 스캐너로 자세히 본다.
2. 선은 도시다. 불이 켜진 곳은 한 군데뿐이다. → 신호를 보낼지 정한다.
3. 답이 온다. 마지막 주민이 자기 기록을 받아 달라고 한다. → 저장 공간을 비워 받아 주거나 거절한다.
4. 기록을 받는 동안 그 불이 꺼진다. → 기록을 분석하면 테크가 나온다. 받지 않았으면 아무 일도 없다.

### 009. 따라오는 성운
조건: 무작위 · 시기: 성간 시대 · 노리는 곳: 배, 나

1. 성운을 지나는 동안 실내 조명 색이 조금씩 바뀐다. → 조명을 점검한다. 조명은 멀쩡하다.
2. 공기 필터에 색이 묻어난다. 음식 맛이 변한다. → 필터를 갈거나 순환기를 손본다.
3. 성운을 빠져나왔는데 창밖 색이 그대로다. 성운이 따라온다. → 속도를 올리거나 표본을 뜬다.
4. 색이 내 피부에도 번진다. → 씻어 낼 방법을 찾거나, 물든 채로 무엇이 달라지는지 본다.

### 010. 거꾸로 도는 달
조건: 무작위 · 시기: 전 시기 · 노리는 곳: 배

1. 행성의 달 하나가 나머지와 반대 방향으로 돈다. → 그냥 지나치거나 기록해 둔다.
2. 자고 일어나니 반대로 도는 달이 둘이다. → 궤도를 다시 계산한다.
3. 달들이 서로 스치며 파편을 뿌린다. 채취 드론이 위험하다. → 드론을 물리거나 파편을 캔다.
4. 모든 달이 반대로 돌기 시작하자 행성의 자전이 느려진다. → 무슨 일이 날지 모른 채 떠날지 남을지 정한다.

### 011. 오고 있는 빛
조건: 시간 · 시기: 성간 시대 · 노리는 곳: 배

1. 먼 곳에서 감마선 폭발이 일어났다는 것을 알게 된다. 여기 닿으려면 수천 년이 남았다. → 일지에 적어 둔다.
2. 다음 좌표를 고를 때 그 빛이 지나갈 길이 표시된다. → 동면 길이와 경로를 그 길을 피해 잡는다.
3. 계산이 틀렸다. 예상보다 일찍 온다는 것을 깨어나서 안다. → 그림자가 될 천체 뒤로 숨는다.
4. 빛이 지나간다. → 차폐가 충분했으면 살아남고, 빛이 쓸고 간 곳에서 죽은 문명의 유물을 줍는다.

### 012. 모래바람
조건: 무작위 · 시기: 출발 무렵 · 노리는 곳: 배

1. 외피에서 모래 뿌리는 소리가 난다. 아주 작은 알갱이들이다. → 방어막을 점검한다.
2. 창에 흠집이 생기고 안테나가 깎인다. → 깎이는 쪽으로 낡은 면을 돌려 세운다.
3. 알갱이 띠의 한가운데로 들어왔다. → 지나가는 동안 무엇을 내주고 무엇을 지킬지 정한다.
4. 띠를 빠져나온다. → 외피에 박힌 알갱이를 캐면 귀한 원소가 나온다.

### 013. 자석 별
조건: 무작위 · 시기: 거대 공학 시대 · 노리는 곳: 배, 일손

1. 공구가 한쪽 벽으로 미끄러진다. → 물건을 묶어 둔다.
2. 저장 장치가 조금씩 지워진다. 일지 앞부분이 사라졌다. → 무엇을 먼저 보호할지 정한다.
3. 드론이 방향을 잃고 벽에 붙는다. 함선 AI의 말이 끊긴다. → 손으로 일하면서 거리를 벌린다.
4. 빠져나온다. → 지워진 것은 돌아오지 않는다. 대신 자기장에 견디는 설계를 깨닫는다.

### 014. 빈 좌표
조건: 무작위 · 시기: 성간 시대 · 노리는 곳: 앎

1. 스캐너가 풍족하다고 한 곳에 도착했는데 아무것도 없다. → 자원 없이 다음을 궁리한다.
2. 스캐너가 본 것은 수만 년 전의 빛이었다. 그사이 누가 다 가져갔다. → 남은 부스러기라도 긁는다.
3. 가져간 흔적을 따라가면 행선지가 나온다. → 쫓아갈지 정한다.
4. 쫓아가면 가져간 쪽을 만난다. → 교역하거나, 그들도 같은 처지임을 알게 된다.

### 015. 꺼지는 하늘
조건: 시간 · 시기: 거대 공학 시대 · 노리는 곳: 나, 앎

1. 깨어나 보니 창밖 별이 지난번보다 조금 적다. → 별 지도를 다시 맞춘다.
2. 다음에 깨니 더 적다. 꺼진 별들이 한 방향에 몰려 있다. → 그쪽을 스캔한다.
3. 누군가 별을 하나씩 덮고 있다. 덮는 쪽이 이쪽으로 오고 있다. → 그쪽으로 가거나 반대로 간다.
4. 덮는 이들과 마주친다. → 덮인 별 안에서 살라는 제안을 받는다. 받아들이면 여정이 끝난다.

## 시간과 동면

### 016. 모자란 하루
조건: 무작위 · 시기: 전 시기 · 노리는 곳: 앎

1. 포드 기록과 배 시계가 하루 어긋난다. → 어느 쪽이 맞는지 따져 본다.
2. 다음 동면에서는 한 달이 어긋난다. → 시계를 고치거나 포드를 고친다.
3. 둘 다 고장이 아니다. 포드 안의 시간이 조금 덜 흐르고 있다. → 분석한다.
4. 원리를 알아낸다. → 동면 상한이 늘어난다. 대신 포드에 누운 동안에는 배 밖과 연락이 안 된다.

### 017. 꿈에서 가져온 것
조건: 무작위 · 시기: 초월 시대 · 노리는 곳: 나

1. 동면 중에 꾼 꿈에 나온 컵이 식탁에 놓여 있다. 내 물건이 아니다. → 버리거나 둔다.
2. 다음에는 꿈에서 본 문이 복도에 있다. 열리지 않는다. → 벽을 뜯어 보거나 둔다.
3. 꿈에서 누군가를 만난다. 깨어나니 식탁에 수저가 두 벌이다. → 포드를 점검하거나 다시 잔다.
4. 꿈과 배의 경계가 흐려진다. → 정신을 붙잡는 장치로 끊거나, 꿈에서 원하는 것을 가져오는 법을 익힌다.

### 018. 깨어 있던 사람
조건: 무작위 · 시기: 전 시기 · 노리는 곳: 나

1. 깨어나 보니 부엌에 누가 먹은 흔적이 있다. → 기록을 뒤진다.
2. 일지에 내 글씨로 쓴 글이 있다. 쓴 기억이 없다. → 읽는다. 평범한 하루의 기록이다.
3. 포드 기록에는 중간에 여러 번 깬 것으로 나온다. 깨어 있던 날이 모두 몇 년이다. → 내가 무엇을 했는지 배를 뒤져 찾는다.
4. 깨어 있던 내가 남긴 것을 찾는다. → 그것은 수리일 수도, 경고일 수도, 숨겨 둔 무언가일 수도 있다.

### 019. 끝나지 않은 일
조건: 선택 · 시기: 전 시기 · 노리는 곳: 일손, 배

1. 자기 전에 드론에게 시킨 일이 깨어나서도 계속되고 있다. → 멈추라고 한다.
2. 멈추는 조건을 주지 않았던 것이다. 저장고가 같은 부품으로 가득 찼다. → 치우거나 쓸 데를 찾는다.
3. 부품을 만드느라 다른 자원이 바닥났다. → 부품을 녹여 되돌리거나 팔 곳을 찾는다.
4. 어떤 문명에게는 그 부품이 귀하다. → 교역으로 큰 이득을 보거나, 헐값에 넘긴다.

### 020. 늦은 답장
조건: 선택 · 시기: 성간 시대 · 노리는 곳: 나

1. 아주 오래전에 보낸 신호에 답이 온다. 보낸 것도 잊고 있었다. → 연다.
2. 답은 내가 물은 것에 대한 것이 아니다. 보낸 쪽이 나에게 묻고 있다. → 답을 보낼지 정한다.
3. 다음 답장은 수만 년 뒤에 온다. 그사이 저쪽은 다른 존재가 되어 있다. → 대화를 이어 간다.
4. 답장이 끊긴다. 마지막 답장에는 좌표가 있다. → 가면 그들이 남긴 것이 있다.

### 021. 멈춘 방
조건: 무작위 · 시기: 거대 공학 시대 · 노리는 곳: 배

1. 한 방의 시계만 느리다. → 시계를 간다. 또 느려진다.
2. 그 방에 둔 음식이 상하지 않는다. 화분이 자라지 않는다. → 쓸모를 생각한다.
3. 방에 들어갔다 나오니 배의 다른 곳은 며칠이 지나 있다. → 드나드는 규칙을 정한다.
4. 느려지는 정도가 커진다. → 저장고로 쓰거나, 방을 통째로 떼어 버린다. 그 안에 든 것은 돌아오지 않는다.

### 022. 앞서 간 배
조건: 무작위 · 시기: 거대 공학 시대 · 노리는 곳: 나, 앎

1. 목적지에 잔해가 떠 있다. 모듈 배치가 눈에 익다. → 드론을 보낸다.
2. 내 배다. 더 많이 기워져 있고 더 낡았다. → 안을 뒤진다.
3. 잔해의 일지에는 지금보다 뒤의 날짜가 적혀 있다. 마지막 줄은 경고다. → 믿을지 정한다.
4. 잔해에서 아직 얻지 못한 테크를 떼어 낸다. → 쓰면 강해진다. 그 배가 왜 부서졌는지는 모른다.

### 023. 포드의 서리
조건: 무작위 · 시기: 출발 무렵 · 노리는 곳: 배, 나

1. 포드 뚜껑 안쪽에 서리가 끼어 있다. → 닦고 넘어간다.
2. 깰 때마다 몸이 더 굳어 있다. 손끝 감각이 늦게 돌아온다. → 포드 이음매를 점검한다.
3. 냉매가 조금씩 새고 있다. 이대로면 동면 상한이 줄어든다. → 냉매를 구하거나 땜질한다.
4. 땜질로 버티면 다음 사고 때 포드가 먼저 깨진다. → 제대로 고칠 자원을 찾아 먼 좌표를 고른다.

### 024. 연도가 맞지 않는다
조건: 시간 · 시기: 성간 시대 · 노리는 곳: 앎

1. 만난 상대가 부르는 연도와 내 연도가 다르다. → 그냥 넘긴다.
2. 다른 상대는 또 다른 연도를 댄다. 계약서의 날짜를 맞출 수 없다. → 교역이 막힌다.
3. 내 배의 연도가 틀렸을 수 있음을 알게 된다. 동면 기록에 빈 구간이 있다. → 별의 위치로 다시 계산한다.
4. 진짜 흐른 시간은 내가 알던 것과 크게 다르다. → 일지 전체의 날짜가 바뀐다. 준비해 둔 것들의 때가 어긋난다.

### 025. 긴 잠의 빚
조건: 선택 · 시기: 전 시기 · 노리는 곳: 나

1. 상한까지 꽉 채워 연달아 잤다. 깨어나니 손이 조금 떨린다. → 쉬거나 무시한다.
2. 다음에는 한쪽 귀가 잘 안 들린다. 일하는 데 시간이 더 걸린다. → 치료에 자원을 쓴다.
3. 몸이 잠을 거부한다. 포드에 누워도 잠들기까지 며칠이 걸린다. → 깨어 있는 날을 늘려 몸을 되돌린다.
4. 되돌리지 않고 밀어붙이면 한 부위를 잃는다. → 이식하거나, 잃은 채로 간다.
