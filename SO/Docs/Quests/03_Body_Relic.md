# 퀘스트라인 053~076: 몸과 마음, 유물

형식과 읽는 법은 [README.md](README.md)에 있다.

## 몸과 마음

### 053. 폐 속의 서리
조건: 선택 · 시기: 전 시기 · 노리는 곳: 나

1. 공허부식이 난 벽을 맨얼굴로 고친 뒤 기침이 난다. → 넘어간다.
2. 숨이 차다. 걷는 속도가 느려지고 수리에 시간이 더 걸린다. → 진단한다.
3. 부식 가스가 폐에 내려앉았다. 폐 안쪽이 조금씩 삭고 있다. → 치료 장비가 있으면 쓰고, 없으면 일을 줄인다.
4. 그대로 가면 한쪽 폐를 잃는다. → 이식하거나, 숨이 짧은 몸으로 계속 간다. 다음부터는 보호구를 쓴다.

### 054. 떨리는 손
조건: 무작위 · 시기: 전 시기 · 노리는 곳: 나

1. 정밀한 작업에서 실수가 난다. 나사를 떨어뜨린다. → 다시 한다.
2. 손이 눈에 보이게 떨린다. 수리 실패율이 오른다. → 쉬거나 약을 만든다.
3. 영양이 한쪽으로 쏠려 생긴 일이다. 수액만 맞은 날이 너무 길었다. → 제대로 된 음식을 구한다.
4. 음식으로 되돌리면 낫는다. → 못 구하면 정밀 작업은 전부 드론에게 넘겨야 한다.

### 055. 사라진 맛
조건: 선택 · 시기: 전 시기 · 노리는 곳: 나

1. 밥이 맛이 없다. → 양념을 더 넣는다.
2. 무엇을 먹어도 같은 맛이다. 식사로 무드가 오르지 않는다. → 원인을 찾는다.
3. 동면을 너무 자주 드나든 탓이다. 혀의 감각이 돌아오는 데 시간이 걸린다. → 깨어 있는 날을 늘린다.
4. 며칠을 더 깨어 있으면 맛이 돌아온다. → 그 며칠 동안 배는 더 닳는다. 다른 무드 수단을 찾아도 된다.

### 056. 창가의 사람
조건: 무작위 · 시기: 전 시기 · 노리는 곳: 나

1. 창가에 앉아 있는 시간이 길어진다. 무드는 오른다. → 좋은 일처럼 보인다.
2. 할 일을 두고도 창가로 간다. 조작이 가끔 먹히지 않는다. → 일과를 정한다.
3. 하루를 통째로 창가에서 보낸다. 수리가 밀린다. → 창을 가리거나 다른 낙을 찾는다.
4. 창을 가리면 일은 하지만 무드의 바닥이 낮아진다. → 창가 시간을 정해 두는 법을 익히면 영감이 자주 온다.

### 057. 혼잣말
조건: 시간 · 시기: 전 시기 · 노리는 곳: 나

1. 캐릭터가 일하면서 중얼거린다. → 아무 영향이 없다.
2. 혼잣말이 길어진다. 가끔 없는 사람에게 대답한다. → 함선 AI와 대화 시간을 늘린다.
3. 혼잣말 속에 플레이어가 놓친 징후가 섞여 나온다. "저 벽은 어제도 저랬나." → 귀담아듣는다.
4. 말 상대를 만들어 주면 혼잣말이 준다. → 그러면 무드는 안정되지만 그 귀띔도 사라진다.

### 058. 돌아갈 곳
조건: 시간 · 시기: 성간 시대 · 노리는 곳: 나

1. 일지에 고향 이야기가 늘어난다. → 무드가 조금씩 깎인다.
2. 고향 쪽 좌표가 지도에서 자꾸 눈에 띈다. 돌아가는 데 걸리는 시간이 표시된다. → 무시하거나 계산해 본다.
3. 돌아가면 그사이 흐른 시간 때문에 아는 것은 아무것도 남아 있지 않다. → 그래도 갈지 정한다.
4. 가면 폐허와 함께 한 가지 물건을 얻는다. 무드의 바닥이 단단해진다. → 안 가면 향수는 천천히 무뎌진다.

### 059. 잠이 오지 않는다
조건: 무작위 · 시기: 전 시기 · 노리는 곳: 나

1. 밤에 잠드는 데 오래 걸린다. → 다음 날 일할 시간이 준다.
2. 며칠째 못 잔다. 실수가 늘고 화면 가장자리가 흐려진다. → 수면제를 만들거나 일을 줄인다.
3. 약으로 자면 꿈이 없다. 영감이 오지 않는다. → 약을 끊을지 정한다.
4. 원인은 배의 낮밤 주기가 틀어진 것이다. → 조명을 고치면 낫는다. 못 찾으면 지친 채로 동면에 들어간다.

### 060. 거부하는 몸
조건: 테크 · 시기: 성간 시대 · 노리는 곳: 나

1. 새로 이식한 부위가 가렵다. → 약을 바른다.
2. 열이 난다. 이식한 쪽 팔의 힘 조절이 안 돼서 물건을 부순다. → 이식물을 조정한다.
3. 몸이 이식물을 밀어내고 있다. 억제제를 계속 맞아야 한다. → 억제제 재료를 구한다.
4. 떼어 내면 원래대로지만 그 부위는 약해진다. → 버티면 적응한다. 적응한 뒤에는 내 몸의 다른 곳이 낯설어진다.

### 061. 없는 팔의 통증
조건: 선택 · 시기: 성간 시대 · 노리는 곳: 나

1. 기계로 바꾼 팔이 아프다. 아플 신경이 없는 팔이다. → 진단한다. 이상이 없다.
2. 통증 때문에 잠을 설친다. 무드가 깎인다. → 진통제는 듣지 않는다.
3. 팔을 바꾸기 전의 기억을 떠올리면 잠깐 멎는다. → 옛 물건을 꺼내 곁에 둔다.
4. 몸을 얼마나 바꿨는지가 쌓일수록 이런 일이 는다. → 정신을 붙잡는 수단을 갖추거나, 아픈 채로 익숙해진다.

### 062. 거울
조건: 시간 · 시기: 거대 공학 시대 · 노리는 곳: 나

1. 세면대 거울 속 얼굴이 낯설다. → 넘어간다.
2. 캐릭터가 거울을 피한다. 그 방에 들어가면 걸음이 느려진다. → 거울을 떼거나 둔다.
3. 출발할 때 찍은 사진을 찾는다. 닮은 곳이 거의 없다. → 사진을 걸어 둘지 정한다.
4. 걸어 두면 변하는 속도가 느려지고 무드가 흔들린다. → 치우면 편해지고 더 빨리 변한다.

### 063. 딸깍
조건: 선택 · 시기: 성간 시대 · 노리는 곳: 나

1. 기분을 바로 올려 주는 장치를 얻는다. 누르면 무드가 찬다. → 한 번 써 본다.
2. 쓸 때마다 다음에 필요한 양이 는다. 밥과 책으로는 무드가 덜 오른다. → 줄일지 정한다.
3. 쓰지 않으면 무드가 바닥으로 떨어진다. 캐릭터가 스스로 장치 쪽으로 간다. → 장치를 잠그거나 버린다.
4. 끊으려면 며칠을 아무것도 못 하고 버텨야 한다. → 못 끊으면 캐릭터는 장치 앞에서 일어나지 않는다. 엔딩 중 하나다.

### 064. 생일
조건: 시간 · 시기: 전 시기 · 노리는 곳: 나

1. 함선 AI가 오늘이 생일이라고 알려 준다. 몇 번째인지는 계산이 안 된다고 한다. → 넘어가거나 챙긴다.
2. 챙기려면 자원이 든다. 케이크 하나에 며칠 치 식량이 들어간다. → 만들지 정한다.
3. 만들면 무드가 크게 오르고 한동안 유지된다. → 안 만들면 아무 일도 없다.
4. 다음 생일은 수만 년 뒤에 온다. → 그때도 챙기는지가 일지에 쌓인다. 끝까지 챙긴 사람에게만 열리는 것이 있다.

## 유물

### 065. 무게가 변하는 상자
조건: 무작위 · 시기: 성간 시대 · 노리는 곳: 배

1. 주운 상자를 저장고에 둔다. 다음 날 선반이 휘어 있다. → 바닥으로 옮긴다.
2. 무게가 날마다 다르다. 가벼운 날은 떠오른다. → 무게를 기록한다.
3. 무게는 가까운 별까지의 거리에 따라 변한다. 저울이 아니라 자다. → 분석을 건다.
4. 원리를 알면 스캐너 없이도 주변 천체를 읽는다. → 모른 채 두면 무거운 날 바닥이 뚫린다.

### 066. 노래하는 금속
조건: 무작위 · 시기: 성간 시대 · 노리는 곳: 나

1. 주운 금속 조각이 가끔 운다. 높은 소리다. → 시끄러워서 통에 넣는다.
2. 통에 넣어도 들린다. 우는 때가 정해져 있다. → 때를 적는다.
3. 사고가 나기 조금 전에만 운다. → 곁에 두면 경보기가 된다.
4. 점점 자주 운다. 사고가 늘어서인지 금속이 예민해져서인지 모른다. → 믿고 매번 점검하거나, 소리를 끈다.

### 067. 씨앗
조건: 무작위 · 시기: 전 시기 · 노리는 곳: 나, 배

1. 유물 속에서 마른 씨앗이 나온다. → 심어 보거나 보관한다.
2. 싹이 튼다. 자라는 데 물과 빛을 많이 먹는다. → 다른 작물 자리를 내준다.
3. 열매를 맺기까지 아주 오래 걸린다. 동면을 여러 번 넘겨야 한다. 그동안 돌볼 장치가 필요하다. → 자동 급수를 만든다.
4. 깨어나니 열매가 달려 있다. → 맛은 무드를 크게 올린다. 씨는 다시 얻을 수 있다. 돌봄이 끊겼으면 마른 줄기만 있다.

### 068. 지도
조건: 무작위 · 시기: 성간 시대 · 노리는 곳: 앎

1. 얇은 판에 점과 선이 새겨져 있다. → 별 지도와 겹쳐 본다. 맞지 않는다.
2. 맞지 않는 이유는 아주 오래전의 하늘이기 때문이다. → 별들의 움직임을 거꾸로 돌려 맞춘다.
3. 표시된 곳 가운데 하나가 지금도 갈 수 있는 거리에 있다. → 간다.
4. 그곳에는 지도를 만든 이들이 숨긴 것이 있다. → 다만 그들이 숨긴 이유도 거기 함께 있다.

### 069. 달라지는 책
조건: 무작위 · 시기: 초월 시대 · 노리는 곳: 앎, 나

1. 주운 책을 읽는다. 모르는 글자인데 뜻이 조금 들어온다. → 계속 읽는다.
2. 다시 펴니 내용이 다르다. 내가 방금 겪은 일이 적혀 있다. → 덮거나 더 읽는다.
3. 뒷부분에는 아직 일어나지 않은 일이 적혀 있다. → 믿고 대비할지 정한다.
4. 대비하면 적힌 일은 안 일어나고 그 쪽이 백지가 된다. → 읽을수록 책이 얇아진다. 마지막 쪽에 무엇이 있는지는 다 써야 안다.

### 070. 열쇠
조건: 무작위 · 시기: 전 시기 · 노리는 곳: 앎

1. 무엇을 여는지 모르는 열쇠 모양의 물건을 줍는다. → 보관한다.
2. 그 뒤로 들르는 곳마다 맞는 구멍이 있는지 살피게 된다. 좌표 힌트에 "잠긴 것 있음"이 뜨기 시작한다. → 찾아다닐지 정한다.
3. 맞는 구멍을 찾는다. 열면 또 다른 열쇠가 나온다. → 계속 찾는다.
4. 여러 번 끝에 마지막 문이 나온다. → 그 문은 배 안에 낼 수 있는 문이다. 어디로 통하는지는 열어야 안다.

### 071. 얼음 속의 사람
조건: 무작위 · 시기: 성간 시대 · 노리는 곳: 나, 배

1. 떠다니는 포드를 건진다. 안에 누가 얼어 있다. → 배에 들인다.
2. 포드가 전력을 먹는다. 깨울 방법은 모른다. → 전력을 대 줄지 정한다.
3. 분석하면 깨울 수 있다. 다만 깨우면 한 사람 몫의 식량과 공기가 더 든다. → 깨울지 정한다.
4. 깨우면 잠깐의 말 상대가 생긴다. 그 사람은 자기 시대로 돌아가고 싶어 한다. → 내려 주거나, 다시 재우거나, 계속 얼려 둔다.

### 072. 장난감
조건: 무작위 · 시기: 전 시기 · 노리는 곳: 나

1. 용도를 모르는 작은 기계를 줍는다. 손에 쥐면 움직인다. → 가지고 논다. 무드가 오른다.
2. 가지고 놀수록 움직임이 복잡해진다. 나를 따라 한다. → 계속 놀아 준다.
3. 어느 날 그것이 드론의 고장 난 부분을 건드려 고친다. → 놀이였는지 학습이었는지 모른다.
4. 일을 시키면 잘한다. 그러나 일을 시키면 더는 놀지 않는다. → 장난감으로 둘지 일꾼으로 쓸지 정한다.

### 073. 따뜻한 돌
조건: 무작위 · 시기: 전 시기 · 노리는 곳: 나, 배

1. 손바닥만 한 돌이 늘 체온만큼 따뜻하다. → 주머니에 넣는다. 무드가 조금 오른다.
2. 곁에 둔 날은 잠을 잘 잔다. → 침대 머리맡에 둔다.
3. 돌이 놓인 방의 방사선 수치가 조금 높다. → 멀리 둘지 정한다.
4. 차폐 상자에 넣으면 안전하지만 따뜻하지 않다. → 그대로 두면 잘 자고 천천히 병든다.

### 074. 렌즈
조건: 무작위 · 시기: 거대 공학 시대 · 노리는 곳: 앎

1. 투명한 원반을 통해 보면 물건의 윤곽에 빛이 돈다. → 배 안을 둘러본다.
2. 곧 고장 날 부분만 빛난다. → 점검 도구로 쓴다.
3. 어느 날 내 손을 보니 빛이 돈다. → 무엇이 고장 나려는 것인지 찾는다.
4. 렌즈는 고장이 아니라 끝이 가까운 것을 보여 준다. → 창밖 별에 대 보면 어느 별이 먼저 꺼질지 안다.

### 075. 조각난 기계
조건: 무작위 · 시기: 성간 시대 · 노리는 곳: 앎

1. 큰 기계의 한 조각을 줍는다. 혼자서는 아무것도 안 한다. → 보관한다.
2. 다른 곳에서 맞물리는 조각을 줍는다. 붙이면 미지근해진다. → 조각이 있을 만한 좌표를 찾는다.
3. 조각이 늘수록 기계가 배의 전력을 끌어다 쓴다. 무엇을 하는 기계인지는 여전히 모른다. → 계속 모을지 정한다.
4. 마지막 조각을 끼우면 켜진다. → 무엇이 될지는 모은 순서와 빠뜨린 조각에 따라 다르다.

### 076. 전 주인
조건: 선택 · 시기: 성간 시대 · 노리는 곳: 배

1. 교역으로 얻은 장치를 설치한다. 잘 돌아간다. → 쓴다.
2. 장치가 가끔 내가 모르는 좌표로 신호를 보낸다. → 막거나 둔다.
3. 누군가 찾아온다. 그 장치는 도둑맞은 것이라고 한다. → 돌려주거나, 값을 치르거나, 모른 척한다.
